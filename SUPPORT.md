# Support

Use [GitHub Discussions](https://github.com/ZachDreamZ/universal-phone-harness/discussions) for setup and usage questions.

Use [GitHub Issues](https://github.com/ZachDreamZ/universal-phone-harness/issues) for reproducible bugs and scoped feature requests.

For security issues, follow [`SECURITY.md`](SECURITY.md).

Include Python version, operating system, backend, phone OS, redacted command output, and reproduction steps. Never post credentials, phone contents, screenshots with private data, or full device serial numbers.
